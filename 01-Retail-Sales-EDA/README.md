# Task 1: EDA on Retail Sales Data

## Objective
Perform Exploratory Data Analysis on retail sales data to identify sales patterns, customer behaviour, and actionable business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset inspection and data cleaning
- Descriptive statistical analysis
- Monthly and quarterly sales trends
- Customer demographics analysis
- Top 10 best-selling products
- Revenue by product category
- Correlation heatmap
- Business recommendations

## Files
- Retail_Sales_EDA.ipynb
- retail_sales_dataset.csv

## Conclusion
This project demonstrates practical skills in data cleaning, exploratory data analysis, visualization, and business insight generation.
