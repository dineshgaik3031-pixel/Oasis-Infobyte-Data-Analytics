# Task 2: Customer Segmentation Analysis

## Objective
Apply clustering algorithms to segment an e-commerce company's customer base into distinct groups based on purchasing behaviour, enabling targeted marketing strategies.

## Technologies Used
- Python
- Pandas
- Scikit-learn (K-Means)
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset loading and structural inspection
- Missing value handling and data cleaning
- Descriptive statistical analysis
- Customer purchasing behaviour analysis
- Feature selection using RFM (Recency, Frequency, Monetary)
- Data standardization using StandardScaler
- Optimal cluster selection using the Elbow Method
- K-Means clustering implementation
- Customer cluster visualization using scatter plots
- Cluster profiling and interpretation
- Customer distribution analysis using bar charts
- Marketing recommendations for each customer segment

## Key Concepts
- Customer Segmentation
- RFM Analysis
- Feature Scaling
- K-Means Clustering
- Elbow Method
- Unsupervised Machine Learning

## Files
- Customer_Segmentation.ipynb
- customer_data.csv

## Business Applications
Customer segmentation helps businesses identify high-value customers, understand purchasing patterns, improve customer retention, and develop targeted marketing campaigns.

## Conclusion
This project demonstrates practical skills in data preprocessing, customer behaviour analysis, unsupervised machine learning, K-Means clustering, data visualization, and business insight generation.
