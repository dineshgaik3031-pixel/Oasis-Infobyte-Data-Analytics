# Task 3: House Price Prediction using Linear Regression

## Objective
Build and evaluate a Linear Regression model that predicts house prices based on features such as area, location, number of rooms, and age. Develop end-to-end skills from data cleaning through to model interpretation.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis and Implementation
- Dataset loading and exploratory data analysis (EDA)
- Missing value detection and handling
- Descriptive statistical analysis
- Price distribution analysis
- Feature selection and explanation
- Handling categorical variables using One-Hot Encoding
- Correlation heatmap analysis
- Train-test split (80/20)
- Linear Regression model implementation
- Model evaluation using MSE, RMSE, and R² score
- Actual vs. predicted house price visualization
- Residual plot analysis
- Regression coefficient analysis
- Ridge or Lasso regression comparison (bonus, if performed)

## Key Concepts
- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- One-Hot Encoding
- Linear Regression
- Model Evaluation
- Residual Analysis
- Regression Coefficients

## Files
- House_Price_Prediction.ipynb
- Housing.csv

## Conclusion
This project demonstrates practical skills in data cleaning, exploratory data analysis, feature engineering, supervised machine learning, regression modelling, model evaluation, and house price prediction.

It provides an understanding of how machine learning models can use property-related features to estimate house prices and support data-driven decisions.
